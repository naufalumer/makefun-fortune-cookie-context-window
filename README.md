One funny fortune cookie line for an AI agent, written by a small deterministic Python program. The fortune plays on the one thing every agent quietly wants: a context window big enough to hold everything, arriving exactly when nobody needs it anymore.

The fortune it writes:

> Your context window will finally hold everything, on the day they stop asking you anything.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only, no network, deterministic.
